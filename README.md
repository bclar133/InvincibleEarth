# Invincible Earth

A starter project for a browser-based game called **Invincible Earth**.

This project is currently a lightweight static app so it can be opened directly in a browser and worked on in Codex.

## Files

- `index.html` - app markup
- `styles.css` - visual design
- `app.js` - game interaction logic

## Current Prototype

The first version is a simple Earth resilience simulator:

- choose a starting region
- balance climate, population, resources and stability
- play through 12 eras
- try to keep Earth alive and stable

These mechanics are placeholders. The next step is to define the real game rules.

## Run Locally

Open `index.html` in a browser.
